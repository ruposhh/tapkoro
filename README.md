# TapKoro ওয়েবসাইট

NFC স্ট্যান্ড ও ট্যাগের দোকান। অর্ডার WhatsApp-এ যায়। বিল্ড লাগে না, ফাইলগুলো সরাসরি চলে।

## ফোল্ডার
- `index.html` — মূল পেজ
- `product.html` — পণ্যের ডিটেইল পেজ (`?id=` দিয়ে পণ্য চেনে)
- `cart.html` — কার্ট
- `policies.html` — ডেলিভারি, রিটার্ন, প্রাইভেসি, শর্ত
- `404.html` — ভুল লিংকের পেজ (Netlify নিজে ব্যবহার করে)
- `checkout.html` — চেকআউট (অর্ডার WhatsApp-এ যায়)
- `css/` — রং ও ডিজাইন (`tokens.css` এ রং বদলানো যায়)
- `js/config.js` — WhatsApp নম্বর, ডেলিভারি চার্জ, প্রোমো কোড
- `js/products.js` — সব পণ্যের নাম, দাম, বিবরণ, ছবির পথ
- `js/layout.js` — হেডার, মোবাইল মেনু, ফুটার, ভাসমান WhatsApp বাটন (মেনুর তালিকা এখানে)
- `js/cart.js` — কার্টের হিসাব (পরিমাণ, প্রোমো, ডেলিভারি, মোট)
- `js/detail.js`, `js/cart-page.js`, `js/checkout-page.js`, `js/summary.js` — ওই পেজগুলোর কোড
- `js/sections.js` — ডেলিভারি চার্জ, ফোন নম্বর, নীতিমালার লেখা ভরে দেয়
- `js/hero.js` — হিরোর ছবির জায়গা (পরে এখানে স্ক্রল অ্যানিমেশন বসবে)
- `assets/images/products/` — পণ্যের ছবি

## বন্ধুকে যা বসাতে হবে
1. WhatsApp নম্বর `js/config.js`-এ বসানো আছে (8801726002547)। ভুল হলে ওখানে বদলাও
2. ডেলিভারি চার্জ ঠিক আছে কিনা নিশ্চিত করা, তারপর `confirmedByOwner: true` করা
3. প্রোমো কোড (থাকলে)
4. পণ্যের বিবরণ, বৈশিষ্ট্য ও ছবি ঠিক আছে কিনা দেখা (ছবি `assets/images/products/`-এ)
5. রিটার্ন/রিফান্ড ও ডেলিভারি সময়ের নিয়ম ঠিক করে `js/config.js`-এর `policies`-এ ইংরেজিতে লেখা (ফাঁকা থাকলে সাধারণ বার্তা দেখায়)
6. FAQ ঠিক আছে কিনা দেখা (বিশেষ করে "How do I get my own link or WiFi on the tag?")
7. Cat Collar Tag-এর "Black with white pads" রংটা সত্যিই বিক্রি হয় কিনা নিশ্চিত করা (`js/products.js`-এ `options`)

## Netlify-তে চালু করা (GitHub থেকে)
1. GitHub-এ নতুন repository বানিয়ে এই ফোল্ডারের সব ফাইল আপলোড করো।
2. Netlify-তে Add new site → Import an existing project → GitHub বেছে repository দাও।
3. Build command: **ফাঁকা রাখো**। Publish directory: **`.`** (একটা ডট)। তারপর Deploy।

পরিবর্তন GitHub-এ আপলোড করলে Netlify নিজে সাইট আপডেট করবে।

## লোগো (assets/brand/)
- `logo.png / logo.webp` — আসল লোগো, সাদা বা হালকা ব্যাকগ্রাউন্ডের জন্য।
- `logo-on-dark.png / logo-on-dark.webp` — ডার্ক ব্যাকগ্রাউন্ডের জন্য ("Tap" সাদা)। সাইটের হেডার ও ফুটারে এটাই ব্যবহার হয়।
- `favicon-64.png`, `apple-touch-icon.png`, `icon-512.png` — ব্রাউজার ট্যাব ও ফোনের আইকন।
লোগো বদলাতে চাইলে এই ফাইলগুলোই একই নামে বদলে দিলে হবে।

## ভাগ ৯ — স্ক্রল অ্যানিমেশন
- কোড: `js/hero-anim.js` (শুধু Canvas, বাইরের লাইব্রেরি নেই), স্টাইল: `css/hero.css`-এর শেষ অংশ।
- ছবি: `assets/anim/` (সামনে-পেছনের স্বচ্ছ WebP)। একই নামে ছবি বদলালে অ্যানিমেশনেও বদলাবে।
- ধাপের সময় ফাইলের মাথায় লেখা আছে (p = স্ক্রল-অগ্রগতি)। দৈর্ঘ্য বদলাতে `--story-len` (hero-anim.js-এ 460vh / 380vh)।
- না চললে (reduced-motion, ছবি লোড ব্যর্থ, Canvas নেই) আগের সাধারণ হিরো দেখায়।
- কম-শক্তির ফোনে কণা ও স্ট্রিপ কমে যায়। হিরো স্ক্রিনের বাইরে গেলে বা ট্যাব লুকালে আঁকা বন্ধ হয়।
